North Agent Cloud

A one-stop cloud platform for AI agents, from build and run to launch.从构建、运行到上线的一站式 AI Agent 云平台。

  • Scheduling, sandbox isolation, egress control, credential custody and end-to-end tracing; deploys fully offline and on-premises, including on Chinese ARM servers.调度编排、沙箱隔离、出网管控、凭证托管、全链路追踪；支持离线私有化部署，含国产 ARM 服务器。
  • Runtime and sandbox scale separately; lazy start and automatic reclamation fit about 10x more sandboxes on the same resources.运行时与沙箱分离、各自伸缩；懒启动加自动回收，同样的资源承载约 10 倍的沙箱。
  • Its built-in features, trajectory analysis and building agents by conversation, are themselves agents running on it.平台内置的轨迹分析、对话式构建 Agent，本身就是跑在这个平台上的 Agent。

02Core developer核心开发

North Sandbox

An agent sandbox service: claimed in milliseconds, started on demand.毫秒级认领、按需启动的 Agent 沙箱服务。

  • E2B-compatible and multi-tenant: point the official SDK at it and the core flows run; it is also offered on its own.兼容 E2B 协议的多租户服务：官方 SDK 换地址和凭证即可跑通核心流程，也可独立对外提供。
  • Per-template warm pools cut acquisition to milliseconds; custom templates build on a base image.按模板预热，沙箱认领降到毫秒级；支持从基础镜像派生自定义模板。
  • JuiceFS mounts object storage as the working directory: uploads and file views never start the sandbox, and a paused sandbox keeps its files.JuiceFS 把对象存储挂成工作目录：上传、查看文件不用启动沙箱，暂停后文件都在。
  • Egress is denied by default and never exceeds what the project allows; running time and storage are metered per sandbox and closed out daily.出网默认拒绝，不超过项目允许的上限；按沙箱计量时长和存储，每日封账。

03Built solo, from scratch一人从零建成

North Firewall

An egress firewall that keeps real credentials out of an agent's reach.让 Agent 碰不到真实凭证的出网防火墙。

  • A transparent, chained forward proxy: no agent configuration; HTTPS is audited per request, and an upstream proxy can be chained in.透明的链式正向代理：Agent 不用改任何配置；HTTPS 逐个请求审计，还能再串接上游代理。
  • Allow and deny rules per project and sandbox by domain (with wildcards), IP range and port; deny by default, with a reason code on every refusal.按项目、按沙箱配置域名（含通配）、网段和端口规则，默认拒绝；被拒的请求返回原因码。
  • Credential isolation: agents only ever see placeholders; the gateway swaps in the real key once policy allows the request, so real keys never enter the sandbox.凭证隔离：Agent 只接触占位符，策略放行后才在网关里换成真实密钥，真密钥不进沙箱。
  • It also runs on its own, as an egress proxy gateway for other apps.也能单独部署，作为通用的出网代理网关给其他应用使用。

04Built solo独立开发

Agent Team

A platform that schedules many agents across machines to work in parallel.分布式调度多 Agent 并行协作的平台。

  • Every user gets an isolated, platform-hosted container with their own credentials and permissions; agents sleep when idle and wake on a message; talk to any agent from the web, the mobile app or Feishu.每位用户一个平台托管的隔离容器，凭证与权限按用户隔离；Agent 闲置自动休眠、来消息自动唤醒；网页、手机 App 和飞书都能直接和某个 Agent 对话。
  • An account pool routes each agent across many Claude accounts by cache hits and remaining quota; builds and tests go over SSH to compute machines.号池统一管理多个 Claude 账号，按缓存命中和各账号额度用量自动路由 Agent；编译、测试等重活经 SSH 交给计算机器。
  • Nothing counts as done until a second agent has tried, end to end, to prove it broken.每项改动都要经另一个 Agent 端到端对抗验证，证伪不了才算完成。
