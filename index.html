Work作品

01

North Agent Cloud

A platform for building, deploying, and running AI agents.构建、部署和运行 AI Agent 的平台。

  • Scheduling, sandbox isolation, egress control, credential custody, elastic scaling, end-to-end tracing.调度编排、沙箱隔离、出网管控、凭证托管、弹性伸缩、全链路追踪。
  • Runtime and sandbox are decoupled: long, low-load LLM calls and short, high-load tool execution scale separately. Lazy start and automatic reclamation fit about 10x more sandboxes on the same resources.运行时与沙箱分离：长时低负载的模型调用和短时高负载的工具执行各自伸缩；懒启动加自动回收，让同样的资源承载约 10 倍的沙箱。
  • The platform’s own built-in features — trajectory analysis, building agents by conversation — are themselves agents running on it.平台内置的轨迹分析、对话式构建 Agent 等功能，本身就是跑在这个平台上的 Agent。

02

North Sandbox

A multi-tenant sandbox service compatible with the E2B protocol.兼容 E2B 协议的多租户沙箱服务。

  • Per-template warm pools bring sandbox acquisition down to milliseconds.按模板预热，沙箱认领降到毫秒级。
  • JuiceFS over object storage as the sandbox file system: data persists in real time, and volumes can be remounted elsewhere.用 JuiceFS 连接对象存储作沙箱文件系统：数据实时落盘，存储卷可以灵活切换。

03Built solo, from scratch一人从零建成

North Firewall

An egress firewall built specifically for agents, which also runs on its own as a general firewall and proxy.专为 Agent 设计的出网防火墙，也能作为通用的防火墙和代理服务独立使用。

  • A transparent, chained forward proxy: iptables intercepts egress traffic transparently, and CA injection with MITM decrypts and audits HTTPS requests.透明的链式正向代理：iptables 透明拦截出网流量，CA 注入与 MITM 解析、审计 HTTPS 请求。
  • Credential isolation with Vault: credentials are injected as placeholders, so agents only ever see the placeholder and the exposure surface shrinks to a single gateway.凭证隔离 Vault：凭证以占位符注入，Agent 只接触占位符，泄露面收敛到单一网关。

04Built solo独立开发

Agent Team

A control plane for running coding agents in parallel.让编程 Agent 并行开发的控制平台。

  • 5–10 Claude Code and Codex agents a day, 20+ at peak, each in its own git worktree and Kubernetes namespace, with message routing between them.日常并行 5–10 个 Claude Code / Codex（峰值 20+），各自独立的 worktree 和 K8s 命名空间，Agent 之间由平台路由通讯。
  • Minute-level patrol and custom Stop hooks catch the failure modes of long-running work, like an agent that says it will keep going and then stops. Nothing counts as done until a second agent has tried to prove it broken.分钟级巡检和自研 Stop hook 治理长程任务的典型失效——比如说了要继续却停下；每项改动都要经另一个 Agent 端到端对抗验证，证伪不了才算完成。
  • 1,400+ commits. My merged pull requests went from about 32 to about 212 a month after it went live.1400+ 次提交；上线后我个人月均合入 PR 从约 32 个增至约 212 个。
